# ACL-ZH Benchmark

The benchmark will compare ordinary Chinese prompts with ACL-ZH prompts on the same coding tasks.

Planned metrics:

- task success rate;
- first-pass success rate;
- constraint violation rate;
- unrequested change rate;
- wrong-file modification rate;
- clarification count;
- rework loops;
- tool calls;
- token usage;
- validation pass rate.

Initial model targets include Claude Code and OpenAI Codex.
