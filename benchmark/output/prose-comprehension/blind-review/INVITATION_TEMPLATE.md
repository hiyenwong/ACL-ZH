# External Blind Review Invitation Template

We are validating a small Chinese technical-comprehension benchmark before using it in a human study.

Your task is to check **information equivalence**, not writing quality.

You will receive one local HTML file containing 10 technical items. Each item has a source Fact Sheet and three anonymous versions labeled A/B/C.

Please independently judge whether each version preserves the same information as the Fact Sheet and whether it adds, removes, or changes substantive information.

Important:

- Do not try to identify which version belongs to which writing method.
- Do not inspect the project repository while reviewing.
- Do not discuss scores with another reviewer until both reviews are submitted.
- Use a pseudonymous reviewer ID.
- The review contains 30 cells in total: 10 items × 3 versions.

After completion, export the JSONL file from the page and return it to the coordinator.

The coordinator will aggregate the reviews before opening the hidden mapping key.
