# Contributing to ACL-ZH

ACL-ZH is an experimental controlled-language specification for AI agents.

## Rule proposals

A new rule proposal should include:

1. Problem statement.
2. Ambiguous or unsafe example.
3. Recommended example.
4. Expected effect on agent execution.
5. Whether the rule can be checked deterministically.
6. Possible false positives.
7. Suggested severity: error or warning.

## Design priorities

Rules should improve at least one of:

- execution clarity;
- scope clarity;
- constraint compliance;
- reference resolution;
- control-flow clarity;
- validation and evidence quality.

Avoid rules that only enforce personal writing style.
